# Customer Shopping Behavior Analysis

## Project Overview
Analyzed 3,900 customer records to identify shopping trends, revenue patterns, discount usage, and subscription behavior.

## Tools & Technologies
- Python
- Pandas
- MariaDB SQL
- Power BI

## Key Analysis
- Revenue analysis by gender and age group
- Customer spending and subscription analysis
- Product ratings and discount analysis
- Customer segmentation
- Interactive Power BI dashboard

## Project Files
- Python notebook for data analysis
- SQL file containing 10 analysis queries
- Customer shopping dataset
- Power BI dashboard

## How to Run
1. Open the notebook in Jupyter Notebook.
2. Install the required Python libraries.
3. Configure your own MariaDB connection.
4. Run the SQL queries in MariaDB.
5. Open the Power BI dashboard in Power BI Desktop.
